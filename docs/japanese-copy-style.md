# 日本語の表記・文体

## 文体

- 自己紹介、成果物の説明、研究の説明、開発記録の本文、図の説明文は「です・ます」でそろえます。過去の出来事は「しました・でした」、予定は「します」と書き分けます。
- 見出し、記録の題名、ボタン、状態ラベルは短い名詞句や動詞句を使います。「成果物を見る」を「成果物を見ます」にする必要はありません。
- 文中の疑問形はそのまま使えます。「どう変わるのかを調べています」は敬体です。句末だけを機械的に置換しません。
- 引用、論文の原題、説明用資料の本文、コード識別子は原文を保ちます。
- 本人の自述は「私」でそろえます。AI の担当と本人の判断・検証を区別し、分担の記録がない行為は補いません。

## 用語・操作

- 画面上のラベルと操作説明で同じ呼び方を使います。
- 回答を支える記述は「根拠」、資料やページの所在は「出典」、文字のデザインは「書体」と書きます。
- 件数は日本語の説明を添えます。文献、関連づけ、単体テストを同じ種類の数として扱いません。
- 原則として、サイト内の移動は「→」、同じページ内の移動は「↓」、外部リンクは「↗」で示します。
- 内部向けの編集指示や翻訳管理メモは、公開本文に含めません。

## 数値と研究の範囲

- 数値には、何を測ったか、対象・条件、出典を添えます。
- Coach の 2.46 s は最後の字幕イベントから最終候補の描画完了までの p50 です。音声入力からの総遅延や、各処理の中央値の合計として説明しません。
- 同じ測定の条件は TTS 10文・1回（n=10）、RTX 5060 Laptop GPU です。作者の実動画・89分授業での自用と、第三者試用・母語話者レビューを区別します。
- 単体テスト数は実装の確認であり、会話品質や学習効果の指標ではありません。
- 研究の候補・準備・開発時の観察・正式な結論を、言語校正の都合で更新しません。
- 研究の原データとハッシュに結び付いたレイアウトを直接書き換えず、日本語の編集用表示レイヤーを使います。

## メディア

- 一つの主表示領域に出す画像・動画は常に一つです。`hidden` 属性と実際の表示・占有サイズをともに確認します。
- 主画像と動画は元の縦横比を保ち、必要な字幕・候補・警告・説明を切り落としません。
- Coach の履歴と保存フォルダーは補助説明に分けます。Windows エクスプローラーを会話画面として見せません。
- 動画は利用者が再生します。切り替えたときやページが隠れたときは一時停止します。
